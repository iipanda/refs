Refs: v1 UI mocks

"Refs" is a placeholder name. It's a native macOS menu-bar app: capture → source detected automatically → one line about what you like → saved to a local library that agents can read over MCP. These are static mocks for judging layout and flow, not final visuals.

The only always-present UI. It can be hidden in Settings, and the hotkey still works without it. Recent captures are here so you can quickly check what you just saved.

2Capture: selecting an area

After the hotkey, the screen dims and you drag an area, or press Space to snap to a window. The top bar shows which app/site was detected before you release, so a wrong guess is obvious right away. This needs our own selection overlay. With the system screencapture -i picker (the lighter option), this bar disappears and the source is shown on the save panel instead.

Decisions these mocks make. Push back on any of them.

  1. Default hotkeys ⌃⇧2 / ⌃⇧3, chosen not to clash with macOS ⌘⇧3/4/5. Both are rebindable.
  2. The save panel appears every time. An alternative is a "quick save" mode where a capture saves immediately and you add the description later in the Library.
  3. Return on an empty description still saves. The description is encouraged, not required.
  4. The library is grouped by source (Apps vs Websites). There are no folders, boards or manual tags in v1.
  5. The MCP server is read-only in v1, so agents can't delete or edit references.
  6. The source is editable in the save panel, for when detection gets it wrong.
